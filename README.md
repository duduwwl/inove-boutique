# Inove Boutique — site demonstrativo

E-commerce editorial demonstrativo para a Inove Boutique, em Varginha-MG. O checkout, os pedidos, o estoque, os cupons e os horários exibidos não processam transações reais.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Qualidade

```bash
npm test
npm run lint
npm run build
npm run test:e2e
```

Stack: Next.js 16, React 19, TypeScript, Tailwind CSS 4, Zustand, GSAP, Radix UI e Playwright.
